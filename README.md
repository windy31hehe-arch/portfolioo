# Портфолио — одностраничные сайты

Три демо-лендинга для разных ниш. Каждая страница — **один файл `index.html`**:
без конструкторов, без сборки, без внешних библиотек, шрифтов и картинок.
Открывается двойным кликом даже без интернета и грузится мгновенно.

| Демо | Ниша | Что показывает |
|---|---|---|
| [demo-remont](demo-remont/index.html) | Ремонт квартир | светлая тема, мини-калькулятор стоимости, 3 тарифа, объекты, FAQ |
| [demo-clinic](demo-clinic/index.html) | Стоматология | запись на приём, карточки врачей, тарифы лечения, блок доверия |
| [demo-barber](demo-barber/index.html) | Барбершоп | тёмная тема, прайс-наборы, запись с выбором мастера и времени |

Главная страница портфолио — [`index.html`](index.html): открыть её, чтобы перейти к любому демо.

## Что сделано в каждой работе

- адаптивная вёрстка под мобильные (проверено на 360, 768 и 1200 px);
- структура под продажу: первый экран, услуги, цены, отзывы, частые вопросы, форма заявки;
- форма с валидацией и подсказкой, куда подключить реальную отправку (Formspree или Telegram);
- базовое SEO: `title`, `description`, Open Graph для нормального превью ссылки в мессенджерах;
- доступность: `:focus-visible`, подписи к полям, `aria`-атрибуты, `prefers-reduced-motion`.

## Технологии

HTML5, CSS3 (переменные, Grid, `clamp()`), vanilla JavaScript.
Ни одного внешнего запроса — все иконки нарисованы инлайновым SVG.

## Как посмотреть локально

Откройте `index.html` в браузере. Всё.

## Важно

Все компании, имена, цены и отзывы в демо — **вымышленные**. Это шаблоны для портфолио,
не связанные с реальными организациями.
